Usage

Helm v3 must be installed. Each module is a repository at https://helm.digit.org/<project>/<module>:

helm repo add digit3-core https://helm.digit.org/digit3/core helm repo update helm install my-release digit3-core/<chart-name> -n <namespace> -f values.yaml

Open a project above to see its modules, then a module to browse its charts, versions and release history.
