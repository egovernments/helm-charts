Backbone Common Core Usage Guide

Usage

Helm must be installed to use the charts. Please refer to Helm's documentation to get started.

Once Helm is set up properly, add the repo as follows:

helm repo add digit-backbone https://helm.digit.org/backbone helm repo add digit-core https://helm.digit.org/core helm repo add digit-common https://helm.digit.org/common

You can then run helm search repo digit-backbone to see the available charts.

Installing a chart

helm install my-release digit-backbone/<chart-name> -n <namespace> -f values.yaml

Updating dependencies

Most core charts depend on the common library chart. Build dependencies before installing:

cd charts/core/<chart-name> helm dependency build
