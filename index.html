The DIGIT platform, packaged.

Install and upgrade DIGIT services with Helm. Charts are organized as projects, modules and service charts - each module is its own Helm repository.

Browse projects Read the docs
add a module
# each module is a Helm repository
helm repo add digit3-core https://helm.digit.org/digit3/core
helm repo update
helm install my-release digit3-core/<chart> \
  -n <namespace> -f values.yaml
Repository pattern: helm.digit.org/<project>/<module>
